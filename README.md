# 🧪 Practice-Projects

This repository contains a collection of beginner-to-intermediate Python practice projects. Each project focuses on strengthening core programming concepts such as control structures, functions, logic building, and problem-solving. 🚀

---

## 📁 Projects Included

### 1️⃣ Bagels – A Number Guessing Game  
🎯 **Objective:** Guess a secret 3-digit number using logic and clues  
🛠️ **Technologies:** Python  
🔍 **Features:**
- Random 3-digit number generation
- Logic-based clue system (Fermi, Pico, Bagels)
- 7 guess limit with detailed feedback
- Menu system with options to view rules or exit
- Fully terminal-based interface

📊 **Status:** ✅ Completed  
📄 **File:** `Bagels.py`

---

### 2️⃣ Blackjack – Terminal-Based Card Game  
🃏 **Objective:** Play against the dealer to get as close to 21 as possible without busting  
🛠️ **Technologies:** Python  
🔍 **Features:**
- Card dealing system with suits and values
- Ace handling as 1 or 11 based on the situation
- Hit/Stand gameplay flow
- Dealer’s automated logic (stand at 17+)
- Betting system with virtual currency
- Bust detection, payout logic, and balance tracking
- Option to view rules or exit from the menu

📊 **Status:** ✅ Completed  
📄 **File:** `Blackjack.py`
