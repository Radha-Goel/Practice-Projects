### 1️⃣ Bagels – A Number Guessing Game  
🎯 **Objective:** Guess a secret 3-digit number using logic and clues  
🛠️ **Technologies:** Python  
🔍 **Features:**
- Random 3-digit number generation
- Logic-based clue system (Fermi, Pico, Bagels)
- 7 guess limit with detailed feedback
- Menu system with options to view rules or exit
- Fully terminal-based interface
